# 关于这个博客

## 技术栈

- **框架**: VitePress
- **部署**: GitHub Pages
- **主题**: 默认主题 + 自定义配置

## 目录结构

```
blog/
├── docs/
│   ├── .vitepress/
│   │   └── config.ts    # 配置文件
│   ├── posts/           # 文章目录
│   ├── public/          # 静态资源
│   └── index.md         # 首页
└── package.json
```

## 写作规范

- 文件名用 kebab-case
- 每篇文章开头写标题
- 文末注明发布日期
